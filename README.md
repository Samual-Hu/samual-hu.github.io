## 使用

- 播放／暂停：中间播放按钮或空格。
- 上一段／下一段：两侧按钮或左右方向键。
- 点击曲线或关键手：进入该手的完整讲解专题。若先讲比较图，再出现实战落子，将从相关比较图开始。
- 目差／胜率切换：曲线右上角。
- 进度条与阅读倍速可用；当前没有静音或重听控件。
- URL的 `#move=28` 可直达白28的讲解专题。
- 电脑及手机布局都保持曲线可见，长讲解在文字区内滚动。

## 历史音频实现（当前停用）

全部音频由文字新合成，未截取原视频声音，未克隆讲者声线。使用Microsoft Edge在线语音服务的云希预设音色，由edge-tts预先合成并保存为静态MP3。播放时只读取本站文件，不调用TTS服务，不需要API密钥。

多音字按用户2026年10月22日的纠正处理：围棋动作“长”读cháng，“粘”读zhān。独立词典只在合成输入中替换为“常”“沾”，显示原文不变；“漫长”“成长”等普通词不套用围棋动作规则。Antigravity中的Gemini 4 Argon (Medium)提供样本听辨；该环境没有原生音频合成工具。

edge-tts是非官方客户端，未来服务接口可能变化；已有MP3不受接口变化影响。没有配置付费API，也不向访客暴露凭据。

## 静态部署

本目录无需构建。通过普通HTTP静态服务器或GitHub Pages提供即可。入口为index.html，data/lecture.json保存播放顺序、只读局面、注释、曲线及音频索引，audio/存放预生成配音。
